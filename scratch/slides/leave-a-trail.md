# Leave a trail

Make your paper folder something a co-author could rerun. Then do it with one of your own.

---

# Look at your folder

- The PDF, and a text copy of it. It turned the PDF into text before it could read it.
- Scripts: every step of the fix, written down.
- Results and figures, made by those scripts.
- It's a mess. That's normal.

No folder? Ask: *"Download vibing.jonasmoss.com/messy-project.zip into this folder and unzip it."*

---

# Why text

| | Invisible | Visible |
|---|---|---|
| **Writing** | Word: you can't see what changed | Text: every change shows |
| **Data** | Clicking in Excel: no record | A script: the steps are the record |

- The agent reads and writes text, and so can you, in Notepad.
- Writing in LaTeX? That's text already.
- Writing in Word? Keep Word for the paper. Keep the rest in text, and ask for a Word copy when you need one.

---

# When there is no record

- Norway's oil fund: one wrong date in a spreadsheet, 1 December instead of 1 November. It cost about $92 million (disclosed 2024).
- Excel turns gene names into dates. About 31% of genomics papers with gene lists in Excel had the error.
- The eventual fix: geneticists renamed the genes.

---

# Git: a save point

- Before it moves anything: *"Set up git here and commit everything."*
- From then on, nothing it does is permanent. You can always go back.
- You don't learn git commands. You ask.
- First time? *"Set up git with my name, …, and my email, …"*

---

# Exercise: organise it

1. *"Organise this folder so a co-author could rerun everything. Show me the plan first. Don't move anything yet."*
2. Argue with the plan. Then let it run.
3. *"Write a README for a co-author, and a project file for you."*
4. *"Commit."*

---

# The test

1. `/clear`. It now knows nothing about this folder, like a new co-author.
2. *"Rerun everything from scratch. Do you get the same numbers?"*
3. Not the same, or it can't? Ask what's missing, and fix the README.

---

# See what changed

- *"What changed since the last commit?"*
- Every file moved, every line edited, listed.
- *"Go back to the last commit"* undoes it all.

---

# Now your own folder

- Copy a real project folder, and work on the copy.
- Same steps: commit, plan, organise, README and project file, the test.
- Not a folder with personal or confidential data.

---

# Round-up

- Did the rerun give the same numbers the first time?
- What couldn't be rebuilt?
- A wrong script you can read beats a right click you can't remember.
