# examples/leave-a-trail — instructor key for "Leave a trail"

Deck: `content/slides/leave-a-trail.md` (`/slides/leave-a-trail`). Handout:
`handouts/leave-a-trail.md`. Runs straight after "Take a paper apart", after the
break (Finance: after lunch). About 50 minutes, then the own-folder block.

| Minutes | What |
|---|---|
| 5 | Look at your folder, why text, one story |
| 5 | Git: a save point |
| 20 | Organise, README and project file, commit |
| 10 | The test (`/clear`, rerun) and "what changed?" |
| 10 | Round-up, then straight into "Now your own folder" |

## The plain-text thread, start to finish

Plain text is argued once, here, but it starts earlier:

1. **Profile block** ("What it knows about you"). The profile is a text file: the
   exercise ends with *"Open my profile in Notepad."*
2. **Paper block.** Say it out loud when the answers come back: *"It turned the PDF
   into text before it could read it."* And when the fix runs: *"That script is the
   record of what it did."* No slide; two sentences.
3. **This block.** The argument, with their own folder as the evidence.

Keep it cost-framed, not moral. Not "open science is good" but "a co-author, a
referee or you next spring can rerun this in a minute instead of a weekend".

**Show of hands at the start of the session: LaTeX or Word?** It tells you how to
pitch "Why text". LaTeX users are already writing in text; for them the news is git
and the rerun test. Word users keep Word for the paper; the point is everything
around it.

**One story, not both.** Finance: Norway's oil fund, one wrong date in a spreadsheet
(1 December for 1 November), about $92 million, disclosed 2024. The employee's own
account: "It was a manual mistake. My mistake."
([Slashdot, from the FT](https://it.slashdot.org/story/24/02/12/211251/the-norwegian-sovereign-wealth-funds-92-million-excel-error).)
Others: the gene names, where the fix was renaming the genes.

## Git

- Most people will have installed it from the install handout (Step 5). **Git for
  Windows needs admin rights**: winget's `--scope user` still triggers a UAC prompt
  (winget-pkgs issue #369735, open as of May 2026). Anyone without admin rights skips
  the git steps; everything else in the block works without git.
- The first commit fails without a name and email. The slide has the line; the agent
  sets it.
- "Go back to the last commit" throws away uncommitted work. It's on the slide as
  information. Don't run it live unless you have just committed.

## The practice folder (`messy-project/`)

For anyone who has no folder to organise (they never reached the fix step). They
ask the agent to download `vibing.jonasmoss.com/messy-project.zip` and unzip it.
Generated by `scratch/examples/scripts/make-trail-example.py` (synthetic, reproducible, standard
library only, so the shipped script runs on any Python 3).

A survey experiment: monthly vs yearly price framing, outcome willingness to pay
(NOK). 240 respondents; 17 speeders; 220 in the cleaned file.

| File | What it is |
|---|---|
| `survey_export_2026-03-14.csv` | raw export, 240 rows |
| `data_clean_FINAL.csv` | cleaned **by hand in Excel**, no script; semicolons (Norwegian Excel) |
| `analysis.py` | dead: reads `data.csv`, which doesn't exist |
| `analysis_v2.py` | the real analysis; writes `table1.txt` |
| `table1.txt` | current: N = 220, +53.2 NOK, p = 0.024 |
| `table1 (copy).txt` | older: N = 223, −291.6 NOK, p = 0.260 |
| `notes.txt` | "removed the speeders (under 1 min) in excel", "the crazy WTP ones?? ask Kari" |
| `draft_v3.docx` | Word draft; describes only the speeder rule, reports N = 223 |

**The planted problem.** The cleaning had two rules. One is written down (drop
speeders, under 60 seconds). The other isn't: three willingness-to-pay answers above
5,000 NOK (9,999, 25,000 and 7,500) were deleted by hand. Only a comparison of the
raw and cleaned files shows it. And the conclusion depends on it: with the three
rows, the effect flips sign and stops being significant.

What a good run does:

- Notices the cleaned file has no script, and writes one (`clean.py` or similar)
  from the raw export.
- The rerun test catches a script that only drops speeders: it gives N = 223 and the
  wrong table. The fix is to compare the files, find the second rule, and write it
  down, in the script and in the README.
- Sorts out which table is current, and retires `analysis.py`.
- Bonus, if someone asks it to check the draft against the results: N = 223 in the
  draft vs 220 in the table, and the method section is missing the outlier rule.

That's the story for the round-up: **an undocumented click in Excel decided the
sign of the result, and the rerun test is what found it.**
