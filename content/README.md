# Website content

The participant-facing course pages live here, separately from the website
code.

- `course-overview.md` appears on the homepage.
- `day-1.md`, `day-2.md`, and `day-3.md` are the rough daily guides.
- `slides/opening.md` is the opening deck. A line containing only `---` starts
  a new slide.

Keep these files direct and conversational. They are scaffolding, not a promise
that every timed block is final.
